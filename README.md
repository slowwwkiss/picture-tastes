# picture-tastes

One picture of food: steaming ramen with a jammy soft egg, glistening
chashu, chili oil and green onions — 896x597, 953,923 bytes, under the
gate's 1 MiB / 1024x1024 limits.

`main.ts` (Node 22) writes the prepared `ramen.png` asset byte for byte to
`/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR`). No network, no drawing.
